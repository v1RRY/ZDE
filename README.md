# Installing

For now there is no package in repositories, but you can install ZDE manually. First, you should clone repository:

```shell
git clone https://github.com/ZDesktopEnvironment/ZDE
```

...then, you should install all dependencies:

```shell
pacman -S labwc python3 tk moka swaybg nwg-panel
```

...and copy ZDE to your system:

```shell
cd ZDE
cp -rfv tree/* /
```
